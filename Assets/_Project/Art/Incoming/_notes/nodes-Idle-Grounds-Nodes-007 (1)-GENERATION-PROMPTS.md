# Generation prompts

Built-in image generation produced one transparent pixel-art source per node using the accepted Idle Grounds asset contact sheet as style/palette reference. Subjects followed ART-SPEC §3.7 verbatim: spirit lotus, small and large reed beds, thunder tree, small and large storm spires, bone heap, soulvine, and scar-jade outcrop. Sources were cropped, nearest-neighbor downsampled, quantized to the exact 32-color project palette, and assembled into native horizontal frame sheets.
