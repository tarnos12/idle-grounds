# Golden rice item

`item_wheat.png` uses the existing wheat key but depicts rice, as requested: golden stalks tied with red thread. 32x32 RGBA8, binary transparency and approved palette only; centred 26x27 silhouette with a one-pixel ink edge. Light from upper left.

Unity: PPU 32, Sprite Single, centre pivot, Point filtering, Compression None, mipmaps off, sRGB, Clamp. Display at native size for ground items and integer scale 2x for tooltips.

Created with built-in ImageGen, then nearest-neighbour export, exact-palette mapping, binary alpha and one-pixel edge normalization. Includes prompt, validation and 8x nearest-neighbour preview. The preview is not a gameplay asset. In-game acceptance remains pending. Partial P2 delivery; other requests remain outstanding.
