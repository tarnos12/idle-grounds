# Idle Grounds UI icons

Static transparent icons for the exact manifest keys named by the PNG files. Icons 32x32; inline glyphs 16x16. PPU 32, Point filter, no compression or mipmaps, sRGB, Sprite Single, centre pivot. Unity adds frames separately.

Validated exact size, RGBA 8-bit, nonempty silhouette, project palette and binary alpha. All icons use a separate built-in image-generation call. Source prompts retained in GENERATION-NOTES.json. Generated silhouettes normalized to the native canvas with nearest-neighbour sampling, palette quantization and alpha cleanup.

Limitations: visual clarity should be checked in the game at the intended text/icon scale; do not nonuniformly stretch these sprites. No in-game integration test.
