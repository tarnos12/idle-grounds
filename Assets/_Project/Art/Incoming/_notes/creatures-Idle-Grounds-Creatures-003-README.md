# Idle Grounds — Awakened Dragon 003

`dragon_awake_160x192_4f.png` is a four-frame horizontal breathing loop (640×192; four 160×192 cells). It preserves the accepted coiled pose and mossy rock nest while opening the eyes, adding gold-green scale accents, a restrained gold aura, and animated qi motes.

Import with nearest-neighbour filtering, slice four horizontal frames, play at 6 fps, and use a bottom-centre pivot. The aura is intentionally rendered with hard pixel/dither edges to preserve the project alpha rules.
