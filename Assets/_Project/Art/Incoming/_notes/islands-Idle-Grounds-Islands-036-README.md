# Idle Grounds Islands 036

Quality redo of the five 3/4 front-above underside-only sprites rejected in Islands-035. These versions use generated chunky stratified rock, top-left highlights, deep seams, wrapped roots, hanging moss/vines, and terminal mist dithering. Top cuts remain flat/ragged and contain no grass or top plane. Lava is four 128x160 frames horizontally (512x160). Import at PPU 32, Point, no compression, no mipmaps.
