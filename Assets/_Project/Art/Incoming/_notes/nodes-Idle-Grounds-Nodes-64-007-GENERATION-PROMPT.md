# Generation prompts and derivation notes

Concepts were generated from the accepted Nodes-007 lotus-pad and reed references. Lotus uses the frame-0 pose as one still. Reed cut states were derived directly from the generated intact states so only the upper stalks change and rooted bases remain identical. All concepts were high-alpha cropped, nearest-neighbor resized, exact-palette mapped, binary-alpha, bottom-aligned and connectivity-checked.
