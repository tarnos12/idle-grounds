# Idle Grounds item icons
Generated with built-in ImageGen; isolated cells exported with nearest-neighbour sampling, exact 32-color project palette remapping, binary transparency and ink outline normalization.
Unity: 32 PPU; Point filter; compression None; mipmaps off; sRGB; Sprite Single; pivot Center. Display 1x world, 2x HUD; preserve integer zoom for crisp pixels.
Limitations: generated art is not hand-authored Aseprite; no editable layers. Technical validation is automated; visual/in-game acceptance remains pending. Preview is 8x nearest-neighbour. No animation or baked ground shadow.
