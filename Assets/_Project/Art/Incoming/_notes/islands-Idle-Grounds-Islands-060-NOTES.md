# Idle Grounds — Islands-060

Thunder Crag P2 tileset for ART-SPEC v6.16. Includes all seven P2 files plus the canonical blob-mask reference. P3 scatter and spark are intentionally deferred.

Native pixels, PPU 32, exact P01–P32 palette. Blob alpha matches Center v5, cliff alpha matches Islands-030, and side-wall alpha matches Islands-034. All alpha is binary except the accepted cliff-wall fade.

Delivered for review when uploaded; not accepted or integrated.
