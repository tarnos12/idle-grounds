# Idle Grounds Buildings 006

Paper Mill, Infusion Array, Loom, Mill: static sprites and four-frame working loops. Static is pixel-identical to animation frame 1. RGBA8 PNG, 96x128 cells, 384x128 strips, exact project palette, binary transparency, bottom-centre aligned.

Unity: PPU 32, Point filtering, Compression None, mipmaps off, Clamp, sRGB. Static Single; loops Multiple, slice 96x128 without gaps, pivot bottom centre, play 8 fps. Preview PNGs are review-only at 2x.

Native ImageGen art was nearest-neighbour exported and remapped to the exact 32-colour palette, alpha thresholded to binary, and translated to bottom centre. No programmatic substitute imagery. Visual inspection confirmed the four required distinct workshop subjects and frame motions.

Limitations: generated animation can show slight structural drift between frames; loop timing and in-game acceptance remain pending. Small tools may simplify at native size. This batch does not replace any accepted P1 assets.
