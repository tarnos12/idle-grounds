Idle Grounds — P2 buildings batch

Files
- bld_furnace_spirit.png — 32x48 tiny stone furnace spirit/brazier.
- bld_charcoal_pit.png — 96x128 earthen charcoal mound kiln.
- bld_herb_garden.png — 96x128 raised glowing-herb garden.

Usage
- Import as single sprites, pivot bottom-centre, pixels per unit 32.
- Nearest-neighbour filtering and no texture compression.

Validation
- Exact dimensions, ART-SPEC P01-P32 palette, RGBA binary alpha.
- Transparent margins and bottom ground contact.

Limitations
- The Furnace Spirit is deliberately simplified heavily at 32x48; flame-face and orange role colour remain readable.
- Charcoal smoke is static in this base sprite; animated smoke can use the separate FX sheet.
