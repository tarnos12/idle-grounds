# Idle Grounds — rounded cliffwall repair

Seven P1 32 px biome strips replace the rejected flat-band delivery. Each uses the accepted straight-wall pixels from Islands-030 frames 0–2, preserving chunky blocks, upper-left light, roots/moss/snow/lava, and the P01–P32 palette.

The four frames use broad rounded lower silhouettes with a 16 px, four-step alpha fade. Shared three-pixel seam bridges and identical edge alpha profiles allow arbitrary frame order. Waterfall frames and other large vertical motifs were excluded.
