# Generation prompts and derivation notes

Each intact state was generated from the accepted Nodes-006 reference: a pale-jade herb bush, one segmented bamboo stalk, and a connected three-stalk bamboo clump. State 1 was derived directly from state 0 so only picked/cut regions change and the base remains identical. Concepts were cropped at high alpha, nearest-neighbor resized, exact-palette mapped, made binary-alpha, bottom-aligned and connectivity-checked.
