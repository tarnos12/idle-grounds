# Idle Grounds Islands 032

Fishing macro second redo after in-game review. Four cool-family P05/P06/P27 shingle decals, low contrast, sparse pebbles, binary-alpha dithered edges, no warm tan or brown. Import PPU 32, Point, no compression, no mipmaps. Built-in image generation supplied the art-direction pass; final sprite was reconstructed and validated at exact native pixels.
