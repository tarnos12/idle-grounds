# Idle Grounds — Islands-059

Lotus Marsh P2 tileset for ART-SPEC v6.15. Includes the eight P2 files and canonical blob-mask reference. P3 scatter is intentionally deferred.

Technical: native pixels, PPU 32, exact frame layouts, P01–P32 only. All alpha is binary except the accepted cliff-wall fade inherited from Islands-030. Blob alpha is identical to Center v5; fill frame 0 equals blob frame 46. Side-wall alpha is identical to Islands-034.

Status: delivered for review when uploaded; not accepted or integrated.
